## ChatGPT 充值、代充与成品账号有什么区别？

搜索“ChatGPT 充值”时，你可能要的是会员开通或续费，也可能要的是 API 余额。这两种需求应先区分。

- **原号代充**：给你指定的现有账号办理会员，适合希望继续使用原账号的人。先确认账号当前订阅状态及可办理条件。
- **成品账号**：购买另一个账号的交付服务，不等于为你原来的账号续费。付款前确认账号使用权限、有效期和交付内容。
- **API 余额**：用于程序通过 API 调用模型，不能把 ChatGPT 会员购买视为 API 充值。Codex 使用 ChatGPT 登录和使用 API Key 的计费路径也不同，见 [Codex 指南](docs/codex-recharge-guide.md)。

如果希望自行开通，可以先查看 [OpenAI 官方套餐与计费说明](https://learn.chatgpt.com/docs/pricing)，按官方支持的地区、支付方式及账号条件办理；本仓库的价格表是店内服务报价，不是官方定价。
